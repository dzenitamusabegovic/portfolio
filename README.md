# dzenitamusabegovic.com

Personal portfolio, hosted on GitHub Pages. Plain HTML/CSS/JS — no build step.

## Editing content
All personal content lives in the `SITE` object at the top of **`script.js`**:
name, email, location/timezone, rotating roles, "Currently" list, toolkit,
projects, experience and social links. Edit it there and push.

- `index.html` — page structure
- `style.css` — design (colors are CSS variables at the top)
- `CNAME` — tells GitHub Pages to serve at dzenitamusabegovic.com; don't delete it.
